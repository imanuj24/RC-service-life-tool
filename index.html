About this tool

This tool implements regression-based equations for service life prediction of reinforced concrete incorporating supplementary cementitious materials (SCMs) under chloride exposure conditions.

Binder systems

  • OPC — Ordinary Portland Cement
  • FA — Fly Ash (20–40% replacement)
  • GGBS — Ground Granulated Blast Furnace Slag (30–70%)
  • SF — Silica Fume (5–15% replacement)

Valid design space

  • Cover depth: 45–80 mm
  • w/b ratio: 0.30–0.50
  • Exposure: chloride / coastal

Selected models

Each model was validated against an independent test dataset, with R² values between 0.93 and 0.97 across all four binder systems.

Disclaimer

This tool is intended for preliminary design guidance only. Results should be verified by a qualified engineer. Predictions are valid within the stated design space; extrapolation beyond the recommended parameter ranges is not advised.
